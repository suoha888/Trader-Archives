# 我的致富思维

总结一下我致富的原因：
1. 冒险精神：我从小就很喜欢去探索未知，愿意承担风险。一旦发现一个新的商机，只要我感兴趣，我就会去尝试。我从不怕尝试商机而带来的亏损，因为我懂得控制好风险，而且每一次尝试之后无论赚钱与否，我一定能学到新的东西。
2. 独立意识：我一直都不喜欢被控制，尤其是被强势的人控制，我更喜欢去控制别人。我很难，也很讨厌成为别人的一枚棋子，我一直都只允许自己掌控全局，自己掌握自己的人生。
3. 延迟满足：我愿意为了更美好的未来去牺牲当下，在我的价值观中，没有“活在当下”这个概念。我愿意放弃当下的娱乐去拥抱学习，因为我知道学习能在未来给我带来金钱的回报。我愿意暂时不买一样昂贵的消费品，因为我知道同样的金钱如果被我用去投资，则可以在未来赚到更多的钱。延迟满足=未来收获更多=我的快乐
4. 合作意识：我知道世界上有很多人都比我更聪明，所以我应当与他们合作。我明白单打独斗无法做出大事业，一定要和与自己更聪明的人合作才能到达更远的地方。
5. 风控意识：并不是每一个商机都能成功，事实上，以往真正让我赚到钱的商机只占1/5，大多数商机是让我亏损或不赚不赔的，所以我一直都有很强的风险控制意识。我从来都只会拿自己输的起的钱去尝试新的商机，在我只有2000块的时候我就拿500块去尝试新的商机，在我有100万的时候我就拿10万去尝试新的商机。满仓All IN从来都不是我的风格，我更欣赏“大胆的小心”风格。
6. 生财意识：我一直都觉得把钱存进银行定期是很愚蠢的，一下子让自己丧失流动性的同时还很容易错过好机会。所以我会花很多时间去研究宏观经济与投资标的，让我有能力好管理自己的财富，获得不错的收益并且保有充足的流动性，在有新商机出现时可以立马拿钱出来尝试。
7. 慕强意识：我会有意识的与各个领域的强者做朋友，因为我可以从他们身上学到新东西。并且这些厉害的人在以后很大概率以后会有合作的机会。
8. 跳跃性思维：我很擅长把无关的事物组合起来合并成一个新的解决方案。把A的技术和B的资源结合起来再卖给C是我的常用商业技巧。从A手上买到货物，再卖给求货无门的B从中空手套白狼也是我的常用手段。
