# 患得患失：金融投资与情场之大忌

投身金融投资行业也有一年了
研究情感心理学也有一年了
说我观察到的金融投资与情场非常相似的点吧：那就是在你投入其中之后，一旦出现患得患失的心态，那你就大概率真的会遭受损失墨菲定律：“越是会担心的事情就越是会发生”
是什么导致患得患失的心态？是因为你下了超过心理【可承受损失范围】的注，简单的来说就是你输不起，所以一旦有一点账面亏损就会慌的手忙脚乱。而在手忙脚乱的情景下，人会失去理智，做出的决策往是极其错误的。在情场上，出现患得患失的心态就意味着你是弱势的“需求方”，必然会陷入被动。
金融市场上谁赚钱谁赔钱？大部分富人是赚钱的，大部分穷人是赔钱的。这是为什么呢？因为富人拿1000万去炒股，赔掉了一半也不会影响他开豪车住豪宅，富人有极大的心态优势，可以让他更理性的做出决策，更容易赚到大钱。而穷人呢？拿着他好几年辛苦攒下的10万块钱去炒股，赔了一半心态就崩溃了，想着自己辛苦积攒了1.5年的钱打水漂了，就开始唯诺患得患失，开始进行不理性的交易操作，最后亏钱割肉离场。
情场上谁输谁赢？最后往是高价值的人赢，低价值的人输。因为高价值者有足够多的“行情筹码”在手，不缺这一个，所以会建立很强的心理优势。而低价值者没有那么多筹码，往会有患得患失的心态，就容易进行委曲求全的行为。《简爱》中有一段话可谓是一针见血：“爱是一场博弈，必须永远保持与对方不分伯仲、势均力敌，才能长此以往地相依相惜。因为太强的对手让人疲惫，太弱的对手令人厌倦。”
金融投资和情场，本质上都是一场博弈。要与别人斗，也要与自己的情绪斗，而患得患失是许多人输掉这场博弈的原因。要赢，首先就要确保自己不怕输，要有输光也无所谓的底气，这就是“在战略上要藐视敌人，在战术上要重视敌人”的灵活运用。
