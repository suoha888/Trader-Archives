# 年轻真好，具有无限的可能。真的就有无限的可能吗？

- **Author**: Vida · 方程式新闻 (@Vida_BWE)
- **Authorship**: 本人原创 · 知乎回答
- **Date**: 2025-01-14
- **URL**: https://www.zhihu.com/answer/79222973825

---

是的，年轻人就是有无限的机会的，因为：
1. 年轻人不需要很在意合规。我现在体量大了之后很多时候想到一些商机我都没法做了，因为我要考虑合规问题，不能触犯法律，而年轻人则不用怕。
比如说我想发个币赚韭菜的钱，但是我这么做就会给我留下污点，让我成为被远洋海底捞的潜在对象，所以我做不了。而年轻人光脚的不怕穿鞋的，随便发就完事了，因为搞你的利润小于成本。
比如说AI色情、AI任意照片做任意动作（你懂的），这种AI其实对于大厂来说开发起来都是易如反掌的，但是他们即使做出来了也无法对公众开放、收费，因为他们会面临各种法律诉讼合规问题，而小的AI厂商和个体则不怕，打一枪换一地就可以了。这种月入千万上亿人民币的AI色情产业现在都是被小团队小个体给赚了，而大厂则被结节限制。
2. 年轻人时间便宜。很多好的套利类型商业点子我就算想到了，也没有合规问题，但是我就是没时间去做。
- 比如帮去世的人生产墓碑二维码，还可以帮亲属用AI“复活”去世的人作为增值服务。
- 比如世界上大部分人还不知道克隆技术已经很成熟，能克隆出长得一模一样的宠物，所以可以去做宠物克隆厂商的代理帮他们宣传拉客吃返点。
- 比如可以做一名帮中年（70、80后）富人做跨国资产配置、资金自由流动的顶级顾问，其实有大量大量这样的中年富人有这个需求，只是他们没有很灵活的信息渠道。用自媒体宣传自己拉客，帮他们搞定一站式全包服务。
3. 年轻人能冒险能试错，摔倒了失败了也无所谓，只要不去搞那种贷款梭哈某个资产或者某个生意的莎币行为，那么你有很多试错机会。
对于大部分已经富了的人来说，已经没有能耐再清零一次，一旦这种事情发生那么心态直接崩了。年轻人不一样，摔了你也损失不了多少，拍灰又能站起来了。
4. 给中产阶级的年轻人的话：不要以为富二代有多么多么了不起，不要以为差距有多么多么的大，以为那象牙塔很高。
很多二代其实很懒很废。别乱听一些媒体鼓吹说什么富二代从小培养有多么优质巴拉巴拉，其实很多人也不过是享乐主义的废柴罢了。现在是信息时代，很多工业时代致富的老一辈老钱并没有把《获取并利用优质信息》的能力传承给他们的后代（他们自己都不会），所以这也是年轻人的机会，拥抱信息时代的每一个机会，拥抱人工智能、跨境电商、加密货币这类新兴产业，在这种全新的领域的竞技其实非常公平。你努力努力，其实获胜的概率不比他们低多少。而老的工业产业则是他们的地盘，留给他们吃就好了。
