# 加密资产配置战略核心要义

公认的最好的投资方法是逆周期投资，在传统市场的表现为：在基准利率高时多配置股票，在基准利率低时多配置债券。
加密市场应该反过来：在基准利率低时多配置现货，在基准利率高时多配置美金本位套利。
传统市场中，基准利率是由政府设定调控的，基准利率越高则导致投资人投资意愿下降导致资产价格缩水，基准利率越低市场借贷成本越低则投资人投资意愿增加，进而导致资产价格增长。
加密市场中，基准利率是由市场自由定价的。币价越高则人们投资意愿越狂热进而导致基准利率越高，币价越低则人们投资意愿越低迷而基准利率越低。
注：加密市场的基准利率=defi借贷、交易所借贷、做多资金费率等一切借USD途径的平均年化利率
