# 去泰国或者东南亚国家旅行还安全吗？你还敢去吗？

我在泰国定居了一年，昨天也去TG上看了很多《劳务》《园区》《骗招》《妙瓦底》关键词的频道的信息补了一下功课客观的来说一说：
泰国安全吗？当然没中国安全
绑架存在吗？存在。但是随机路上看到个游客就撸人上车绑走的那种基本没有。都是有预谋的，和电信诈骗一样是有固定套路的。从绑匪的角度上来看：你怎么确保绑到的人不是哪个重要人物或者正在和朋友通着话而惹出大麻烦呢？你怎么确保目标能乖的在泰国不反抗你，乖的被你运到缅甸被你拿捏呢？那就必须想出一个噱头让对方信服。
为什么会出现把人绑到缅甸妙瓦底园区的情况？因为2020开始打击电诈之后，中国人开设的电诈园区以他们以往的高薪招人困难成本变高，加上敏感户籍出入境管控使得很多老员工回中国了就出不来了。出现了用人荒的情况。所以出现了很多“骗招”。这个骗招不光是以各种高薪诱惑，还可能是：和你说是背债撸银行的钱，说要让你在泰国躲一躲，然后实际上把你运到缅甸妙瓦底。还可能是：在小红书上找女生旅游搭子，然后和你上车之后拿武器把你胁迫之后运到缅甸妙瓦底。
泰国政府是否对此知情是否主动参与？官方层面不会，他们靠旅游业每年稳当几千亿人民币收入，没必要去惹这种麻烦事。但是泰国下面的警察，各种职级，都是贪污的。在泰国长居的人都知道，如果路上违章了，被警察抓到就塞点小费就能免正式处罚，过海关护照有问题也可以花钱买“保关”。泰国的警察大部分是工资低且没有执法记录仪的。所以有一方警察和妙瓦底的骗招人头贩子们勾结，是很正常的，也是毫不意外的。比如在关卡的警察就算看到一个未验明身份的人在后座，要被送去缅甸，可能司机塞点打个招呼警察就放行了。有的绑架犯可能即使被抓，公司花个几十万美金，也就把他保出来潜逃了。
缅甸妙瓦底是一个独立与缅甸的存在，被军阀控制，和缅甸政府翻脸，属于“第四世界”，电诈园区也是在军阀的保护下运营。但是妙瓦底的水电网食物都是泰国供应的，要是泰国方面一断供，那么妙瓦底的各个园区很快就停摆。这大概也是为什么泰国军方一个电话就能把王星捞回来。
还能去旅游吗？你害怕就暂时不去就好了。
要去的人遵循一个原则也能很大程度保障你的安全：1. 你必须是真的去放松旅游而不是去干任何赚钱的工作 2. 只和关系好的有武力值的人去泰国 3. 在海外不要和《在网络或现实中主动勾搭你的中国人接触》，海外华人们应该都知道老乡专坑老乡的道理 4. 冷知识：短刃折叠瑞士军刀是可以合法带上任何国家的飞机托运/高铁的，要好运用不出所料的话，泰国政府因为这则舆论损失几百上千亿人民币旅游收入了。缅甸妙瓦底买人卖人骗招也彻底上了中央的目光。
100%未来中泰会有行动打击妙瓦底的。妙瓦底苏将军现在估计头都大了。
害怕来旅游的人，等你未来看到妙瓦底的将军也和缅北四大家族一样被铲除，该抓的园区老板和主管被抓，猪仔全遣返。
彻底没有这种骗招绑架的新闻之后，那你再考虑是否来就好。这样也算是为我们在泰国的华人的安全做一份贡献，把压力给到中国和泰国警方来解决现在确实存在的问题。
