# 正向反馈带领我们走向光明人生

正向反馈——用通俗易懂的话来讲就是“我付出就有回报”，它是一种神奇的奖励机制，会不断鞭策被作用者【要做得更好】来获得更多的满足感。
在学校里学习成绩拔尖的学生往会一直保持他们的好成绩，这不光是他们智商卓越的功劳，他们还往愿意花比普通学生更多的时间去学习。这是因为他们的好成绩给他们带来了老师和家长的表扬与在校园内的名望，所以他们有比普通学生更多的动力去追求更好的成绩。
公式：学习=好成绩=表扬与名望=前进的动力
美女往会特别在乎美丽，她们的美丽为她们带来了许多生活中的便利、异性的关注、同性的羡慕，所以她们有非常强的让自己变得更美的欲望，而且她们希望这种美能够保持的越久越好。她们会花比普通女生多的多的多的时间在学习穿着打扮、控制身材和化妆上。
公式：学习=美丽=关注与羡慕=前进的动力
而我对于更多财富的追求也正是来自于正向反馈。财富让我可以满足自己的物质需求，财富让我从一个普通少年变成一个被人羡慕的对象，财富给我机会结识更优秀的人。正是因为先前这些正向反馈，才使得我对财富有那么大的渴望。我希望保持这份优势，并且希望这雪球越滚越大。所以我会花比普通人多的多的多的时间来学习提高对财富的支配能力，这使我真的在不断变得更115富有。
公式：学习=更多财富=满足与羡慕=前进的动力
如果把一个【领域】比做一片土地，我们是矿工，那么正向反馈就像是我们在这片土地上追求的黄金。有些矿工幸运，挖了几锄头就挖出了黄金，他获得了即时的反馈便会更卖力的在这片土地上挖。有些矿工不幸，挖了一阵子没挖出金子，就中途放弃觉得“自己不是做这块的料”。有些矿工不幸但坚持，挖了一阵子没挖出金子，但他没有放弃，继续挖了很久，终于挖出金子，便也从此有了坚定的信念，这片土地上卖力的掘金。
