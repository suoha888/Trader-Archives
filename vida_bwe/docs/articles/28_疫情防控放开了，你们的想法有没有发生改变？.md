# 疫情防控放开了，你们的想法有没有发生改变？

我是共存派，阳的第4天，想法没有改变，坚持开放，并且用消费行动支持经济因为我：
-要自由的进出公共场所不用扫各种码和看行程卡
-要自由的去各个城市游玩，把失去的青春补回来
-要自由的进出国门
-要看到人来人往的人间烟火气
-要看到大型体育赛事在我们国家举办
-不要大规模的以月为单位计的封城
-不要因为一个小区里有一个感染就封整个小区
-不要划地为牢把很多校园、厂区等有宿舍的人员密集场所直接封锁
总结：愿景是在未来的1-2年能够重见2018-2019的正常生活
我目前还在 末，之前几天体验了一波感冒+发烧+咳嗽+关节疼组合拳，不过现在都已经缓解只剩下咳嗽没有褪去亲历过 之后我也明白对于很多有老人与小孩的家庭，这放开的初期应该不太好过但是，自由就是有价格的如果想恢复正常生活，那么每个人都必须做出一点牺牲另外，知乎上回答这些问题的大部分是年龄30+的人所以知乎上的舆论倾向自然是抨击共存派的如果你去年轻人多一点的地方问同样的问题，例如小红书、b站，那么得到的回响会大不一样。
