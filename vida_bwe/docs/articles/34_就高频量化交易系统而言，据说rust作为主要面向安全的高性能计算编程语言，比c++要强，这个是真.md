国内的股票期货之类的我不了解，但是我们团队最近一个月有开始尝试用RUST做crypto的延迟套利目前使用后的感想：
同样的逻辑RUST的处理速度是nodejs和python的10倍以上，速度层面比肩C++应该没问题同样的逻辑和并发量，RUST程序的CPU占用率比python和nodejs写的程序低很多，不知道是什么玄学原理RUST可以单进程调用系统的多个CPU核心，所以做低延迟+密集计算型的程序很合适RUST开发遇到问题了会很麻烦，基本上能解决问题的文档都是英文的，而且遇到小众问题就基本没有现成的解决方案了，都要自己实现，所以对开发人员的英文与技术能力要求很高交易所对于RUST的支持是0，没有任何交易所有现成的库可以调用，全靠开发员手撸，这是它的缺点综上所述，站在一个PM的角度，使用RUST做低延迟量化交易没问题，只要：
你的开发员能力够强并且愿意钻研
心理做好同类型项目开发进展比其他语言推进的慢一些
你的项目没有必须要和其他某个语言写的组件对接的需求（nodejs除外，rust对nodejs的兼容不错）
你的项目没有追求纳秒级这种极限延迟的需求，因为这可能要硬件的什么特殊定制而rust实现起来很难？（我对这一块技术层面也不了解）
