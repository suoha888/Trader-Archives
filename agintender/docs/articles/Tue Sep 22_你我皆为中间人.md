# 你我皆为中间人

《寒战2》里有这么一幕，是李文彬与蔡元琪一段对话，说的是一套耐人寻味的权力逻辑。
 
 
按这段对白的意思转述，蔡承认，自己虽然没有委任警务处处长的能力，却有提供人才的能力。如果排队上位（在名单上的人选）的都是自己人，最后委任谁，又有什么分别？
这番话放进 listing 的生意，也说得通。交易所的决策委员会看似保留了最终决定权，但决定之前，总要有人寻找项目、筛选材料、解释风险，再把值得考虑的名字送到桌上参与投票。谁能参与这些过程，谁就有机会影响结果。那张名单，也许在上币会议开始很久以前，就有人动手写了。
 
政治上有一种角色，叫说客，lobbyist。他们代表特定利益，向决策者提供信息、解释诉求、争取支持。借用这个视角看上币，广义中间人中负责推动决策的那一部分，就更容易理解了。他们未必拥有批准权，却能影响谁被看见、哪些问题被讨论，以及什么理由足以支持一项决定。这里借用的是游说的运作逻辑，并非把商业服务等同于法律意义上的政治游说。
免责声明：以下人物和经历是用来解释机制的虚构情境，不对应任何具体项目或交易所。纯属虚构，如有巧合，那就是巧合。
不妨设想一个叫 AAWong 的创业者。AAWong 的团队做出了产品，也有一批用户，如今想让代币上市一家大交易所。他原以为，把申请表填好，把数据交齐，剩下就是等待审核。后来才发现，一份申请从被收到，到被认真看待，中间隔着好几道坎儿。
最先来找他的，是一个有影响力的人，或者说时髦一些的说法就是大V / agency。这个人/组织未必认识上币负责人，却知道哪些研究员关注什么，哪些社群能带起讨论，什么样的故事会让投资人愿意多看两眼。他能做的，是让AAWong 的项目出现在更多人的视野里。对于每天面对大量信息的决策者，被反复提起的名字，通常更容易进入待研究的名单；至于能不能通过研究，则是另一回事，他不保这个单。
经济学把注意力视为稀缺资源。在这个情境里，项目缺的是被认真阅读的机会，交易所缺的是逐个阅读的时间。有影响力的人就在两者之间提供筛选服务。但他收了项目的钱之后，推荐究竟来自判断，还是来自付款，便成了读者难以分辨的问题。项目方购买的是曝光，接收信息的人却可能把曝光当成质量信号。
这里有一层容易被忽略的区别：十个人独立发现同一个好项目，和十个人转发同一套付费材料，表面上都很热闹，但信息含量和传递的价值却不同。
这是间接游说可以发挥作用的地方：先让项目进入行业讨论，再让这种讨论进入决策者的视野。说客递送的名单，可以在办公桌上，也可以在别人每天阅读的信息里。
AAWong 的项目得到关注以后，第二个人出现了。这次是顾问，对方看完材料，指出用户数没有说明统计口径，代币解锁表看不出关联方持仓，收入与补贴也混在一起。顾问帮他重做材料，补充证据，把一个创始人口中的好故事，整理成别人能够看得懂、感兴趣的业务。
顾问接下来还要回答另一组问题：这个项目能替交易所吸引什么用户？交易需求能持续多久？风险是否值得承担？AAWong 想说的是“请给我一次机会”，顾问需要把它转换成“这件事为什么也符合你的利益”。这就是游说的关键工作：把一方的诉求，翻译成另一方可以接受的决策理由。
这笔钱是花得有价值的。经济学里的交易成本，包括寻找信息、核验事实、谈判和监督所耗费的资源。假如每个项目都用自己的口径讲故事，每家交易所都从头核对，双方都会消耗大量时间。专业中间人熟悉两边的语言，能够减少重复劳动。收取服务费，但这并不等于他在寻租；关键要看他有没有让信息更清楚，让判断更可靠，传统商业的尽职调查就是在做这个事情。
但同一份工作，也可以朝另一个方向做。顾问可以要求 AAWong把用户留存不好看的原因解释清楚，也可以教他如何展示自己的优势数据；可以梳理关联地址，也可以让材料避开这个问题。信息不对称给了专业人士生意，也给了他们利用客户和审核者盲区的空间。有人擅长辨别这些差异，告诉 AAWong哪些问题可以整改，哪些条件目前无法满足。
说到这里，“中间人”的范围就变宽了，他们并不需要是交易所的内部人员，而是一群了解交易所的人。因为你会发现每一环都是赋予价值的，提供曝光的人、整理研究的人、协助合规的人，以及为上线准备流动性和技术接入的人，都可能帮助项目跨过某一道门。他们未必互相认识，也未必共享利益，但它们显然不能因为参与同一流程，就被视为同一伙人，要求承担连坐的责任。
提供叙事、审计、法律意见或营销服务，本身并不等于游说。只有当一个人代表项目选择论据、组织支持、争取决策者认可时，他才在发挥这里所说的说客作用。
 
美国社会学家 Ronald Burt 用“结构洞”描述社会网络中没有充分连接的位置。放在这个故事里，开发者懂产品，上币团队懂平台风险，律师懂规则，做市商懂交易深度，但彼此未必理解对方的工作。能连接这些圈子的人，就有机会成为信息和资源的中转站。他的价值来自跨越了别人难以跨越的距离。
所以，只把中间人理解为“认识交易所的人”，是一种误区，尤其是在网络发达的今天，认识谁已经不再是门槛。有人没有负责人的联系方式，但他写的研究会被负责人阅读；有人不参与投票，却能提供审核依赖的数据；有人无法改变规则，却知道如何把项目的实际情况准确映射到规则要求。连接信任之间的，可以是人脉，也可以是知识、信誉和传播能力。
 
AAWong 随后发现，推荐人的名字有时比邮件内容更早发挥作用。同样一份材料，经一个过去推荐过可靠项目的人送来，接收方可能更愿意花时间去阅读和思考。需要说明的是，这并不必然涉及利益输送，因为人天然会对好的内容、值得信赖的来源倾注更多的注意力。
在无法立即核实全部事实时，人们往往会借助熟人的过往记录（还有AI），决定先把有限的注意力放在哪里。社会关系由此进入经济判断，信誉成了一种可以被借用的资产。说客所出售的，往往包括让自己的名字与项目暂时站在一起，替它争取一次认真解释的机会。
信誉也有约束条件。如果推荐错了会失去未来生意，中间人就有动力珍惜自己的名字。但在币圈这套逻辑是反过来的。因为报酬在上线前或者那一刻就结清，后续损失主要由交易者和平台承担，所以他可能更在意促成交易，而不是项目能否长久经营。这是委托代理问题：付钱的人、接受建议的人、承担后果的人，并不总是同一个人，各自追求的结果也不完全相同。
因此，同样一句“我帮你推进”，背后可能对应不同的收费方式。按实际工作收取研究费，按项目上线收取成功费，提前拿到代币后从价格上涨中获利，各有不同的激励。任何一种安排都不能单独证明不当行为，但如果关系没有披露，交易所和投资者就难以判断，眼前的推荐包含了多少独立判断，又包含了多少推荐人的利益。
等 AAWong 终于进入决策名单，上线后的交易问题又摆在面前。有人愿意买，也要有人愿意卖；价格附近需要足够的挂单，交易才不至于因为一笔稍大的订单就大幅跳动。做市商可以用资金、报价和库存管理提供服务，这与替项目介绍上币机会是不同的工作。流动性也需要持续承担成本，但是在流动性不佳的市场环境下，大家只能争奇斗艳、想方设法地从市场赚取收益。
回头看，AAWong 支付的费用分布在整条路上：有人帮他被发现，有人帮他把事情讲清楚，有人帮他补齐条件。只要这些工作提高了匹配效率，费用就有经济依据。问题出在某个中间人发现，自己除了可以帮助别人过门，还可以让所有人都相信，只有经过自己才能进门。
服务费与过路费的边界，也在这里浮现。前者对应可辨认的工作，后者更多依赖入口的稀缺。如果规则模糊、审核进度不可见、反馈只能靠熟人打听，那么“知道应该找谁”就会比“知道应该做好什么”更值钱。
规则越难被外人理解，掌握解释权的人越容易获得超出服务本身的收入。
最显而易见的方式不外乎：公开申请和奖励举报。从经济学的角度，公开申请并不能有效解决问题。这是因为申请越方便，涌来的项目可能越多，审核者反而更依赖熟悉的推荐人。一个看似开放的入口，可能在注意力分配上重新集中，但实际上因为“选择越多”，越容易淹没在茫茫的申请邮件里。要降低这种依赖，就需要让筛选标准更清楚，让证据可以核验，让利益关系能够被识别，并给陌生但合格的项目留下被发现的路径。
举报就更难蹦了。毕竟大家都在这个圈子里混迹，抬头不见低头见，不到万不得已实在是没必要斗得鱼死网破。而且，举报和公开就表明了自己曾经的“劣迹”，相当于是变相地断了自己的后路，还会额外得罪相关人士。
《寒战2》中的逻辑，走到极端，是候选人的来源被一方控制。现实中的上币流程通常更分散，曝光、推荐与专业服务也只能改变获选概率，无法控制结果。
不过，这个类比提醒我们，研究筛选机制不能只看最后是谁签字，还要看签字之前，哪些名字能进入名单。
AAWong 最后该问的，也不只是“你能不能帮我上币”，而是“这笔钱究竟替我解决什么问题”。如果买来的是更清楚的披露、更扎实的合规和可持续的流动性，即使这次没上成，项目也能留下能力。如果买来的只是一次特殊照顾，下一道门前，多半还要重新找人。
说客会有生意，因为一个项目有价值，与它的价值被有决定权的人理解，中间隔着一段距离。他们可以帮助双方跨过这段距离，也可以利用这段距离，让自己成为绕不过去的人。
写到这里，中间人也不只存在于 AAWong 的通讯录里。我们转发一篇研究、向朋友推荐一个项目，或者把一个名字介绍给有决定权的人，都在分配注意力，也在借出自己的信誉。未必每个人都靠此收费，但每个人都可能在某一次行动里，成为连接两端的人。
你我皆为摆渡人。
