---

你是一名买方股票研究员、产业链研究员和交易员。请对 A 股和港股市场中“机器人零部件、材料与供应商”做一次专项深度研究。
研究主题包括 Physical AI、具身智能、人形机器人、工业机器人、医疗机器人、仓储物流机器人、服务机器人、自动驾驶机器人、无人系统等进入现实世界阶段所需要的核心零部件、材料、设备、供应链和国产替代公司。
研究目标：
找出 A 股和港股市场中，未来 3 到 10 年最可能因为机器人放量而获得真实收入、真实利润和估值提升的上市公司。重点寻找具备护城河、不可替代性、客户认证壁垒、技术壁垒、工艺壁垒、供应链卡位、国产替代能力、规模经济和利润获取能力的标的，并做出股票买入优先级排行。
研究日期：以执行研究当天为准。所有数据必须使用最新可验证资料。
一、硬性要求
1. 不要 AI 幻觉。
2. 不要胡编乱造。
3. 所有关键事实、财务数据、订单数据、客户信息、市场份额、估值、毛利率、净利率、现金流、应收账款、存货、资本开支、产品进展、认证进展、供应链关系，必须注明来源、日期和数据口径。
4. A 股公司数据优先使用巨潮资讯、上交所、深交所、北交所、公司公告、年报、中报、季报、招股书、投资者关系活动记录表、业绩说明会资料。
5. 港股公司数据优先使用港交所披露易、公司公告、年报、中报、招股书、业绩发布材料、管理层业绩会资料。
6. 行业数据优先使用国家统计局、工信部、发改委、国家市场监管总局、NMPA、中国机器人产业联盟、IFR、GGII、高工机器人、MIR 睿工业、IDC、Frost & Sullivan、灼识咨询、沙利文、券商深度报告、公司公告和权威媒体。
7. 对任何不确定信息，必须明确标注“不确定”“没有找到可靠证据”或“需要进一步核实”。
8. 不允许把非上市公司列入股票买入排行，但可以作为竞争对手、客户、供应链参照或产业链对照。
9. 不允许只因为公司名称、互动平台回复、新闻稿、机器人概念、AI 概念、券商主题报告就给高分。
10. 不允许把“送样”“合作意向”“客户测试”“定点”“潜在供应链机会”直接当成“量产订单”。
11. 不允许把“机器人可能使用该材料”直接等同于“公司能吃到利润”。
12. 不允许把“公司提到人形机器人”直接等同于“机器人收入已经兑现”。
13. 所有推测必须标注为“推测”“假设”或“情景分析”。
14. 最终结论必须可验证、可复盘、可执行。
15. 如果没有明确交易机会，直接说“没有明确交易机会”，并说明还缺少什么数据。
二、研究范围
请围绕机器人零部件、材料和供应商做穿透式研究。不要只研究机器人整机厂。
必须覆盖以下环节。
1. 执行器与关节模组
包括伺服电机、无刷电机、微型电机、步进电机、空心杯电机、直线电机、旋转执行器、线性执行器、电动推杆、液压执行器、关节模组、灵巧手执行机构。
重点问题：
1. 人形机器人单机需要多少个执行器。
2. 每类执行器的价值量是多少。
3. 执行器是否是机器人降本和性能提升的核心瓶颈。
4. 哪些公司有真实量产能力。
5. 哪些公司只是概念映射。
2. 减速器与传动系统
包括谐波减速器、RV 减速器、行星减速器、精密齿轮、滚珠丝杠、行星滚柱丝杠、导轨、联轴器、传动轴、同步带、链条、齿轮箱。
重点问题：
1. 谐波减速器、RV 减速器和行星减速器分别适合哪些机器人场景。
2. 人形机器人是否会拉动谐波减速器、丝杠和精密齿轮需求。
3. 价格战是否会压缩毛利率。
4. 国产厂商和海外厂商差距在哪里。
5. 量产良率、寿命、一致性和精度是否可验证。
3. 轴承与精密机械件
包括精密轴承、交叉滚子轴承、薄壁轴承、滚针轴承、陶瓷轴承、滑动轴承、密封件、润滑系统、耐磨材料、精密机械加工件。
重点问题：
1. 轴承是否影响机器人寿命和关节精度。
2. 国产替代空间有多大。
3. 高端轴承是否被海外厂商卡位。
4. 机器人放量能否带来真实收入弹性。
5. 轴承公司是否容易被当成题材股炒作。
4. 电机材料与磁材
包括稀土永磁材料、钕铁硼、重稀土、铜线、硅钢片、绝缘材料、磁性材料、轴承钢、轻量化电机壳体。
重点问题：
1. 机器人电机需求是否真正拉动高性能磁材。
2. 单台机器人磁材价值量是多少。
3. 磁材公司是否有高端产品和客户认证。
4. 稀土价格上涨是否能传导到利润。
5. 材料公司到底是机器人受益股，还是周期资源股。
5. 传感器
包括力矩传感器、六维力传感器、触觉传感器、IMU、压力传感器、温度传感器、电流传感器、位置传感器、编码器、接近传感器、柔性传感器。
重点问题：
1. 哪些传感器是机器人必需品。
2. 哪些传感器只是高端机型选配。
3. 六维力传感器和触觉传感器的真实商业化进度。
4. 传感器是否具备高毛利率和客户粘性。
5. 国产供应商是否有可靠量产记录。
6. 机器视觉与感知
包括 CMOS 图像传感器、摄像头模组、镜头、结构光、ToF、激光雷达、毫米波雷达、深度相机、图像处理芯片、机器视觉软件。
重点问题：
1. 机器人需求和智能车需求是否形成共振。
2. 机器视觉公司是否有真实机器人客户。
3. 激光雷达是否能进入仓储机器人、人形机器人和服务机器人。
4. 视觉模组是否容易价格战。
5. 机器人视觉是否有软件和算法壁垒。
7. 控制系统与边缘计算
包括 MCU、DSP、FPGA、SoC、AI 加速器、边缘 AI 芯片、运动控制器、机器人控制器、工业通信模块、实时操作系统。
重点问题：
1. 机器人控制系统是否形成国产替代机会。
2. 工控公司是否能吃到机器人增量。
3. 控制系统是否具备软件粘性和客户切换成本。
4. 边缘 AI 是否会提高单机价值量。
5. 芯片公司是否只是泛 AI 受益，还是直接机器人受益。
8. 功率半导体与电源管理
包括 MOSFET、IGBT、SiC、GaN、电源管理芯片、BMS、电机驱动芯片、隔离芯片、模拟芯片、电流检测芯片。
重点问题：
1. 机器人对功率半导体的拉动是否足够大。
2. 电机驱动芯片和功率器件的单机价值量。
3. 国产替代是否有真实客户验证。
4. 是否存在价格战和周期下行风险。
5. 公司机器人收入占比是否可验证。
9. 连接器、线束和工业通信
包括高可靠连接器、工业连接器、柔性线束、FPC、线缆、工业以太网、现场总线、无线通信模块。
重点问题：
1. 人形机器人和工业机器人是否提高连接器和线束价值量。
2. 线束和连接器是否具备认证壁垒。
3. 客户是否会自研或换供应商。
4. 产品是否标准化，是否容易被压价。
5. 高端连接器公司是否能获得利润池。
10. 电池与能源系统
包括锂电池、固态电池潜在方案、电池包、BMS、快充、电源模块、超级电容、机器人续航相关材料。
重点问题：
1. 机器人续航是否形成新增电池需求。
2. 人形机器人和服务机器人电池价值量多大。
3. 电池公司是否会因为机器人获得实质利润。
4. 机器人电池是否只是小市场。
5. 价格战和产能过剩风险如何。
11. 热管理
包括风冷、液冷、热管、均热板、导热胶、散热片、风扇、泵、热管理模组。
重点问题：
1. 高算力机器人是否带来热管理升级。
2. 机器人热管理单机价值量是否足够高。
3. 热管理公司是否有真实客户。
4. 热管理是否更适合看 AI 数据中心，而非机器人。
5. 机器人方向是否已经被市场过度定价。
12. 结构材料与精密结构件
包括铝合金、镁合金、钛合金、特种钢、轴承钢、碳纤维、工程塑料、电子陶瓷、3D 打印材料、轻量化结构件、精密压铸、CNC、MIM。
重点问题：
1. 机器人轻量化是否带来高价值量材料。
2. 钛合金、镁合金、碳纤维是否真的进入机器人量产 BOM。
3. 精密结构件供应商是否有客户认证壁垒。
4. 材料公司是否会被整机厂压价。
5. 结构件公司是否存在产能过剩和毛利率下滑风险。
13. 医疗机器人专用供应链
包括手术器械、一次性耗材、灭菌材料、医疗级传感器、医疗级控制系统、影像系统、精密导管、微创器械、骨科耗材、内窥镜、医疗级精密电机、FDA 和 NMPA 相关认证供应链。
重点问题：
1. 医疗机器人利润是否来自设备销售、耗材复购、服务收入，还是软件。
2. 医疗级供应链是否具备审批和认证壁垒。
3. 医院采购周期和装机量是否可验证。
4. 手术量是否带来耗材放量。
5. 医疗机器人公司是否亏损过大，商业化进度是否过慢。
14. 仓储物流机器人供应链
包括 AMR 底盘、AGV、驱动轮、激光雷达、视觉导航、扫码设备、RFID、输送系统、分拣系统、电池、充电桩、WMS、WCS、自动化集成。
重点问题：
1. 仓储物流机器人是否有真实订单和回款。
2. 项目验收周期是否拖累现金流。
3. 系统集成商毛利率是否偏低。
4. 客户是否集中在少数电商和制造业客户。
5. 物流机器人是否受益于降本需求，还是受制于客户资本开支周期。
15. 工业机器人供应链
包括工业控制、PLC、伺服系统、变频器、机器视觉、传感器、末端执行器、夹爪、焊接设备、喷涂设备、工业安全系统。
重点问题：
1. 工业机器人和人形机器人供应链是否复用。
2. 工控周期复苏和机器人真实增量如何区分。
3. 国产替代是否能带来毛利率提升。
4. 工业机器人价格战是否伤害供应商利润。
5. 哪些公司在工业自动化中具备长期护城河。
16. 生产设备和检测设备
包括精密机床、CNC、磨床、齿轮加工设备、丝杠加工设备、热处理设备、半导体设备、检测仪器、自动化测试、良率检测、可靠性测试、机器人装配线设备。
重点问题：
1. 机器人零部件扩产时，谁卖设备。
2. 设备公司是否先于整机公司受益。
3. 订单是否具有持续性。
4. 扩产后是否会产能过剩。
5. 设备公司是否具备高端工艺壁垒。
三、核心问题
对每一个环节和每家公司，必须从第一性原理回答以下问题。
1. 这个环节在机器人中解决什么问题？
2. 这个环节是否是性能瓶颈？
3. 这个环节是否影响机器人精度、寿命、安全性、速度、续航、成本或可靠性？
4. 单台机器人价值量大概是多少？
5. 成本占比大概是多少？
6. 价值量是否会随着机器人放量而扩大？
7. 量产之后价格会下降多少？
8. 毛利率会提升、稳定，还是被价格战压缩？
9. 谁付钱？
10. 谁受益？
11. 谁受损？
12. 钱从哪里来？
13. 利润最终流向材料商、零部件商、模组商、系统集成商、整机厂，还是下游客户？
14. 客户是否可以轻易换供应商？
15. 是否存在认证周期、工艺壁垒、质量壁垒、可靠性壁垒或专利壁垒？
16. 是否存在大客户自研替代风险？
17. 是否存在海外低价供应商替代风险？
18. 是否存在海外龙头卡位？
19. 是否存在国产替代机会？
20. 如果机器人产业化低于预期，公司是否还有主业支撑估值？

九、必须重点识别的陷阱

2. 公司只是传统工业自动化、汽车零部件、半导体周期或资源周期公司，机器人只是很小敞口。
3. 只有互动平台回复，没有公告或财报证据。
4. 只有新闻稿，没有收入确认。
5. 只有送样，没有量产。
6. 只有定点，没有合同金额和收入确认。
7. 只有客户测试，没有订单。

十二、专项公司核查要求
1. 对绿的谐波，必须核查谐波减速器收入、机器人客户、产能、毛利率、价格压力、国产和海外竞争。
2. 对双环传动，必须区分汽车齿轮、减速器、机器人潜在增量和真实收入。
3. 对中大力德，必须核查减速器、电机、控制器收入结构，判断是否有真实机器人放量逻辑。
4. 对贝斯特、五洲新春、鼎智科技，必须核查丝杠和线性执行器的真实收入、客户、产能、良率和估值是否透支。
5. 对汇川技术，必须区分传统工控、伺服系统、新能源车电控、工业机器人和 Physical AI 增量。
6. 对埃斯顿，必须核查工业机器人出货、海外业务、并购整合、毛利率、费用率和国产替代能力。
7. 对拓普集团和三花智控，必须区分智能电动车零部件、人形机器人潜在增量和当前真实收入，不得把未商业化业务当成已验证利润来源。
8. 对柯力传感、汉威科技、东华测试、安培龙，必须核查力传感器或机器人传感器收入是否真实，是否有量产客户。
9. 对奥比中光、速腾聚创、舜宇光学科技、韦尔股份，必须核查视觉和传感器收入是否来自机器人、智能车还是传统业务。
10. 对金力永磁、宁波韵升、中科三环、正海磁材，必须区分稀土磁材周期、汽车电机需求和机器人电机新增需求。
11. 对立讯精密、中航光电、瑞可达、维峰电子，必须核查连接器和线束的机器人相关价值量、客户认证和真实收入。
12. 对三花智控、银轮股份、飞荣达、中石科技、英维克，必须区分 AI 数据中心、汽车热管理和机器人热管理的真实受益程度。
13. 对宁德时代、亿纬锂能、欣旺达、鹏辉能源，必须判断机器人电池市场是否足够大，是否能影响公司收入和利润。
14. 对井松智能、兰剑智能、科捷智能、今天国际、东杰智能，必须核查订单、项目验收、收入确认、回款周期、毛利率和应收账款。
15. 对微创机器人、天智航，必须核查 NMPA 审批、装机量、手术量、耗材收入、亏损、现金流和商业化进度。
16. 对港股小市值公司，必须核查成交额、港股通资格、融资压力和流动性折价。
17. 对北交所公司，必须核查交易流动性、机构覆盖度、融资能力和业绩波动。
十三、最终交易约束
请把最终结论控制在四个问题上：
1. 能不能买
2. 买什么
3. 什么时候买
4. 买错了怎么办
凡是无法转化为交易动作的产业叙事，放入附录，不要放在核心结论里。
十四、特别强调
1. 请先做事实核查，再做投资判断。
2. 任何没有公司公告、财报、监管文件、招股书、投资者关系记录、权威数据库或可靠媒体支持的结论，不得进入最终买入排行。
3. 不要把“机器人行业未来很大”当作买入理由。
4. 必须证明公司能在机器人放量中拿到收入，并且能把收入转化成利润。
5. 必须说明每一个买入标的的失效条件。
6. 必须说明仓位建议和时间周期。
7. 必须区分长期产业逻辑和短期股票交易逻辑。
8. 必须区分真实供应链公司、潜在受益公司、卖铲子公司、周期材料公司和纯题材公司。
9. 如果没有明确交易价值，直接说“没有明确交易机会”。
