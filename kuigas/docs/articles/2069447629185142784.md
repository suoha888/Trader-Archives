# 撸毛跟吃屎

- **Article ID**: `2069447629185142784`
- **Date**: 2026-06-25T22:23:55.043915+08:00
- **Author**: 丰密 (@KuiGas)

---

1、撸毛：
很多人说撸毛已死，确实，当下太难了。
但我必须说，每个人对撸毛的定义不一样，方法和策略也完全不一样。我这里说的，是链上高质量撸毛，也是这一路走来的Kuigas打法：作为很多项目的深度参与者，用高质量Tx成为高质量用户。
我100%可以肯定的是，他们不是简单点任务的人，而是真实的大仓位资金提供者+Gas消耗者+产品测试者+风险承担者，也是很多早期协议最需要的核心用户+忠实用户+高价值用户。
正因为深，所以爱。
正因为有陪伴，所以会有期待，当然也会有失望。
但可以肯定的是，低质量撸毛肯定不行了。以前那套批量号、机械交互、群控系统堆钱包、简单测试任务、最后等项目方开奖的玩法，已经越来越难。女巫、反撸、延期、低分配、不发币、不上所，随处可见。
2、吃屎
有人说，现在还留在币圈，还在撸毛，还在链上折腾的人，就是在找屎吃。
我仔细揣摩了这句话好多遍，这意思是往大了说，还在币圈的，就是吃屎，往小了说，还在币圈撸毛/交易等各种折腾的，就是在吃屎。
这句话难听，但也不是完全没有道理。因为这两年确实有太多项目让人失望了，项目方pua画饼、延期、反撸、女巫、不给交代。用户真金白银交了Gas，提供了流动性，贡献了数据、时间和反馈，最后换来的可能只是一句“感谢参与”。这两年行业里低于认知下限的事情太多了，赚钱效应也明显下降，财富机会也越来越少，2级的k线图俗称鬼画符，狗看了都摇头，
现实的是，币圈的流动性和注意力，已经在被AI、存储、美股这些更大的注意力分流。最直接的是那边天天涨，动不动就十几20倍，币圈天天跌。身边很多人的视野也越来越宽，不再只盯着币圈的三瓜两枣，而是开始看美股、看AI、看真实现金流、看财务报表、看全球资产配置·····
但，我始终相信，今天还愿意留在链上继续折腾的人，必须比以前更清醒，也必须比以前更有信念。不是因为这里一定还有黄金遍地，也不是因为每个项目都值得相信，而是因为这个市场曾经真的改变过很多普通人的命运。
肉眼可见的是，加密账户正在变成普通人连接全球资产的入口，一个账户就可以买卖全球资产，无国界，无kyc，资金效率拉满，我觉得这是我们的机会所在。以前我们说链上，更多是DeFi、meme土狗、NFT、空投和积分等各种；但现在，稳定币、美股RWA、债券商品、预测市场、Pre-IPO，bstocks等甚至更多真实世界资产，都在慢慢进入加密账户，这是几年前完全没想到的。所以我认为只要市场还在，只要早期机会还在，只要普通人可以通过一个钱包连接全球流动性、交易全球资产参与全球项目，那链上的想象空间与吸引力就还在。
每个人的情况不同，资金体量不同，风险承受能力不同，认知阶段也不同。真正的区别在于，你是在盲目吃屎，还是在屎山里积累认知、找到属于自己的位置。
机会还有没有？肯定还有。只是打法变了。很多东西会越来越重要。
我自己的思考与实战还是我前几天总结所说：
🐝亏钱公式 = 成本 + 赔率 + 风险 + 机会 + 策略
只是时代可能真的变了。低质量撸毛正在死去，但高质量链上参与，永远不会死。
无论如何，与大家同在。吃屎就吃屎吧。
与在粪坑里寻找机会的人同在。
