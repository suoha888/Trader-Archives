## 🤖 Atria 30-Key 满血高并发集群与调度器架构

全站各导师子站均配备强大的专属数字孪生策略导师：
1. **30-Key 轮转矩阵**：峰值并发处理能力达 **300 RPM / 300,000 TPM**，可承受 150~200 人同时在线连续提问；
2. **GlobalKeyScheduler 跨站调度器**：利用浏览器 `localStorage` 实现跨页面持久化轮换与均摊，杜绝单个 Key 用量过载；
3. **45 秒自动熔断与静默重试**：任一 Key 遇到瞬时限流或网络抖动，系统毫秒级置入 45 秒隔离冷却名单，并自动调用下一个健康 Key 重试，前端提问者**完全零感知、零卡顿**。

## 📊 数据湖使用说明与 AI Agent 喂料指引

每个导师目录下的 `data/` 文件夹均提供两种标准格式：
* **`*.json`**：包含完整推文元数据（发布时间、原推正文、点赞/转推量、引用关系、配图本地相对路径），最适合 Python 脚本处理与直接灌入 LLM / RAG 知识库；
* **`*.csv`**：采用 **UTF-8-SIG 带 BOM 编码**，Windows Excel、Mac Numbers 直接双击打开**绝对不乱码**，适合人工快速筛选、做数据透视表与回测统计。
