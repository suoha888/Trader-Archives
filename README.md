## 🛠️ 如何新增收录一位 KOL？

只需遵循 3 步平移规范：

1. **产出专属资料库**：使用 `KOL--ziliao` 技能流水线完成该博主推文的抓取清洗、JEV 分拣打分、思维模型提炼与 SPA 生成。
2. **复制子文件夹**：将生成的文件夹平移放入根目录（如 `/chen-xiao/` 或 `/teng-shao/`）。
3. **总门户挂载卡片**：在根目录 `index.html` 的导师名录中添加一个展示卡片，指向该子目录。
